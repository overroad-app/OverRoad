OverRoad를 이루는 네 층위 — 층마다 무엇이 열려야 하는가

OverRoad가 지향하는 것은 네 층위 전체입니다. 그중 지금 열려 있는 조건만으로 구현할 수 있는 층이 Tier 1이고, 이번에 보여 드리는 것이 이 층입니다.
OverRoad · 도로 위 차들의 초연결 하나의 연결망, 네 층위
이 층에서 되는 것
필요한 권한·데이터현대차그룹이 열어 주면 되는 것
필요한 하드웨어차에 달려 있어야 하는 것
필요한 인프라·제도차 바깥에서 갖춰져야 하는 것
Tier 4협력 자율주행
최종 지향점비전
  • 합성 시야: 안개·야간에도 맑은 날 같은 주행 화면
  • 차량 군집 단위의 협력 주행
  • 자율주행을 이루는 한 축
  • 자율주행 시스템과의 통합 (연결망을 보조 입력으로)
  • OS에 내재된 서비스로 편입
  • 자율주행 센서 구성
  • 다른 차의 정보까지 처리할 차량 내 컴퓨팅
  • 정밀 3D 지도
  • 도로변·클라우드 컴퓨팅
  • 안전 인증과 책임 소재 기준
Tier 3차량 간 직접 통신
협력 주행의 시작로드맵
  • 서버를 거치지 않는 차량 간 직접 통신
  • 가려진 시야 공유, 협력 합류
  • 신호 대기 차량의 협력 출발
  • 주행 시스템과의 연동
  • OS 전용 알림 영역
  • C-V2X 직접 통신 모듈
  • UWB·BLE (초근접, 보행자·이륜차)
  • 도로 인프라 연동 (C-ITS)
  • 저지연 통신망
  • V2X 보안 인증 체계
Tier 2센서·데이터 제휴
내비게이션과 통합로드맵 · 일부 구현
  • 서로를 차로 단위로 식별
  • 앱에 참여하지 않은 차까지 표시
  • 내비 지도 위에 주변 차량과 위험 구간
  • 카메라·레이더·ADAS·조향각 신호
  • 내비 지도 표시, 화면 상시 영역
  • 스티어링 휠 버튼, 배터리·충전 곡선, 결제
  • 이미 달려 있는 카메라·레이더
    (추가 장착 없음)
  • 라이다는 장착 차량만
  • GNSS 보정·HD 맵
  • 센서·지도 데이터 제휴
