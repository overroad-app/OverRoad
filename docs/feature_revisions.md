## 05 EV 충전 rev2 (2026-11-05)
사용자 피드백: 충전소의 평균 충전 시간·충전 중 대수, 같은 충전소로 오는 차량의 위치·SoC, 타사 차량까지 반영해
내 도착 순번·대기 시간·충전 완료 시각을 구해야 한다. 내가 충전한 기록이 다른 사람에게 새 충전 정보이자 별점이 되어야 한다.

| 항목 | rev1 | rev2 |
|---|---|---|
| 충전 중 차량 | HyperConnect 차량만 | + 타사 차량: 공공 충전기 상태(충전 시작 시각)로 남은 시간 어림 |
| 평균 충전 시간 | 없음 | 서울 공공 급속 실이용 47.2분으로 시작 → 실측 기록이 쌓이면 대체 |
| 충전 출력 | 100kW 고정 | 정격의 80%로 시작 → HyperConnect 차량의 실측 출력 평균 |
| 오는 차량 | 목적지·ETA | + 도착 시 SoC 어림(남은 거리 소모), 타사 도착은 시간당 도착 수로 통계 어림 |
| 결과 | 앞 대수·대기 분 | 도착 시각 · 내 순번 · 대기 · 충전 시작 · **80% 완료 시각** · 충전 중 차(타사 포함) |
| 대안 충전소 | 대기가 5분 이상 짧으면 | **충전 완료 시각**이 5분 이상 빠르면 |
| 내 충전 기록 | 없음 | 충전이 끝나면 시간·실측 출력이 충전소 정보로 자동 반영, 기여 통계에 집계 |
| 별점 | 없음 | 충전 후 정차 중 ★1~5 → 충전소 별점, 다른 운전자 카드에 표시 |

데이터 출처와 한계
- 공공 충전기 상태: 한국환경공단 전기차 충전소 정보 API(충전기 상태, 충전 시작 일시 등). 시연에서는 `POST /public_status`로 대신 넣는다.
- 내비 SDK의 충전 정보는 충전 사업자 목록뿐이라 상태는 공공 데이터를 쓴다.
- 차종별 배터리 용량·충전 곡선은 반영하지 않음(77.4kWh·일정 출력 가정). 실차 연동은 Tier 2.
- 시연에서는 충전 시간을 60배 빠르게 흘린다(`POST /demo`).

## 2026-11-05 2차 개선 (기능 영상 리뷰 피드백 반영)

### 전체 화면 개편 (모든 기능 공통 → 01·07도 rev2로 다시 녹화)
피드백: 검정·회색 앱 창이 내비를 가린다.
- Pleos는 오른쪽 패널에 앱 하나만 보여 준다. 반투명 창으로 띄워도 아래 내비가 숨겨지고(에뮬레이터 확인), 다른 앱 위에 그리기는 signature 권한이라 불가.
- 해결: **주행 중에는 내비가 앞**. 출발(5km/h 초과)하면 앱이 스스로 내비를 앞으로 부르고, 경고는 플랫폼 **상단 알림(헤즈업)** + 음성으로 낸다.
- 정차 중 앱을 열면 새 화면: 상태 줄 · 둥근 알림 카드 · 본문(대기 안내 / 충전소 지도 / 이모트 카드) · 팩 색 이모트 버튼. 진단 신호 목록은 설정 안으로.

## 관점: 기능이 아니라 엔진 (2026-11-05, 사용자 방향)
HyperConnect의 핵심은 **점유율 기반 + 차량 간 통신**으로 만드는 연결망(감지 → 합의 → 전파) 자체다.
Tier 1~4의 기능들은 이 엔진 위에 탑다운으로 얹는 응용이고, 기능 자체가 목적이 아니다.
그래서 비슷한 기능이 이미 있어도, "같은 엔진 하나로 모든 기능을 국내 최대 점유율 위에서 기본 제공"한다는 점을 내세운다.

## 기능별 유사 서비스 검토 (2026-11-05)
결론: 개별 기능은 대부분 해외 프리미엄 브랜드·내비 앱에 이미 있다. 새로움은 "기능 하나"가 아니라 아래 조합에 있다.
1. **국내 점유율로 밀도 확보**: 차량 간 경고는 장착 차량이 많아야 효과가 난다(Euro NCAP도 VW Car2X 평가에서 같은 한계를 지적).
   현대차그룹은 국산 완성차 판매의 90% 이상이라, 자사 충전소·자사 망이 아니어도 공공 도로·공공 충전망을 바로 덮을 수 있다.
2. **차량 신호 + 차로 단위 대상 선택**: 같은 차로 뒤차에만 급제동, 옆 차로 접근 차에만 차로 변경 알림 등 "누구에게 보낼지"를 고른다.
3. **사람 사이의 소통(소리 이모트·자동 감사 인사)**: 상용 차량 기능은 찾지 못함. 애프터마켓 뒷유리 LED 표시기만 있음.
4. **추가 설치 없이 소프트웨어로**: VW Car2X는 전용 통신 칩(802.11p), HAAS는 긴급차량 송신기가 필요. HyperConnect는 기존 차량 신호 + 이동통신.
