## 05 EV 충전 rev2 (2026-11-05)
사용자 피드백: 충전소의 평균 충전 시간·충전 중 대수, 같은 충전소로 오는 차량의 위치·SoC, 타사 차량까지 반영해
내 도착 순번·대기 시간·충전 완료 시각을 구해야 한다. 내가 충전한 기록이 다른 사람에게 새 충전 정보이자 별점이 되어야 한다.

| 항목 | rev1 | rev2 |
|---|---|---|
| 충전 중 차량 | HyperConnect 차량만 | + 타사 차량: 공공 충전기 상태(충전 시작 시각)로 남은 시간 어림 |
| 평균 충전 시간 | 없음 | 서울 공공 급속 실이용 47.2분으로 시작 → 실측 기록이 쌓이면 대체 |
| 충전 출력 | 100kW 고정 | 정격의 80%로 시작 → HyperConnect 차량의 실측 출력 평균 |
| 오는 차량 | 목적지·ETA | + 도착 시 SoC 어림(남은 거리 소모), 타사 도착은 시간당 도착 수로 통계 어림 |
| 결과 | 앞 대수·대기 분 | 도착 시각 · 내 순번 · 대기 · 충전 시작 · **80% 완료 시각** · 충전 중 차(타사 포함) |
| 대안 충전소 | 대기가 5분 이상 짧으면 | **충전 완료 시각**이 5분 이상 빠르면 |
| 내 충전 기록 | 없음 | 충전이 끝나면 시간·실측 출력이 충전소 정보로 자동 반영, 기여 통계에 집계 |
| 별점 | 없음 | 충전 후 정차 중 ★1~5 → 충전소 별점, 다른 운전자 카드에 표시 |

데이터 출처와 한계
- 공공 충전기 상태: 한국환경공단 전기차 충전소 정보 API(충전기 상태, 충전 시작 일시 등). 시연에서는 `POST /public_status`로 대신 넣는다.
- 내비 SDK의 충전 정보는 충전 사업자 목록뿐이라 상태는 공공 데이터를 쓴다.
- 차종별 배터리 용량·충전 곡선은 반영하지 않음(77.4kWh·일정 출력 가정). 실차 연동은 Tier 2.
- 시연에서는 충전 시간을 60배 빠르게 흘린다(`POST /demo`).

유사 서비스 검토 (2026-11-05)
- 테슬라: 2023년부터 차량 내비가 도착 시점 수퍼차저 혼잡도와 대기 시간을 예측(다른 테슬라의 이동·과거 이용 반영). 2026년 Google Maps 내장 차량으로 확대(동의자 한정).
- 현대차 E-pit: 만차 시 디지털 대기표·예상 대기 시간 안내, 충전 경로 추천. E-pit 충전소 한정.
- EV Infra 등 충전 앱: 실시간 충전기 상태·사용자 후기. 도착 시점 예측은 확인되지 않음.
- 차별점: 자사 충전망이 아니라 국내 공공 충전망(모든 브랜드)에서, 차량 신호로 만든 실측 출력·충전 기록·별점과
  공공 상태를 합쳐 도착 순번과 완료 시각을 예측. 테슬라가 자사 망에서 하는 것을 현대차그룹이 공공 망 전체로 확장하는 그림.

## 기능별 유사 서비스 검토 (2026-11-05)
결론: 개별 기능은 대부분 해외 프리미엄 브랜드·내비 앱에 이미 있다. 새로움은 "기능 하나"가 아니라 아래 조합에 있다.
1. **국내 점유율로 밀도 확보**: 차량 간 경고는 장착 차량이 많아야 효과가 난다(Euro NCAP도 VW Car2X 평가에서 같은 한계를 지적).
   현대차그룹은 국산 완성차 판매의 90% 이상이라, 자사 충전소·자사 망이 아니어도 공공 도로·공공 충전망을 바로 덮을 수 있다.
2. **차량 신호 + 차로 단위 대상 선택**: 같은 차로 뒤차에만 급제동, 옆 차로 접근 차에만 차로 변경 알림 등 "누구에게 보낼지"를 고른다.
3. **사람 사이의 소통(소리 이모트·자동 감사 인사)**: 상용 차량 기능은 찾지 못함. 애프터마켓 뒷유리 LED 표시기만 있음.
4. **추가 설치 없이 소프트웨어로**: VW Car2X는 전용 통신 칩(802.11p), HAAS는 긴급차량 송신기가 필요. HyperConnect는 기존 차량 신호 + 이동통신.

| 기능 | 이미 있는 것 | HyperConnect의 차이 |
|---|---|---|
| 01 급제동 경고 | VW Car2X(근거리 직접 통신, 고장·사고 차량 경고), Mercedes Car-to-X(급제동·비상등 경고) | 이동통신으로 1.5km까지, 같은 차로 뒤차만. 국내 상용 사례는 확인 못 함(C-ITS는 실증 위주) |
| 01 피드백·신뢰 | Waze "아직 있어요/없어요" 확인, 기여 포인트·배지 | 피드백을 보고 차량의 신뢰 점수로 바꿔 합의 기준에 반영(Waze는 표시 시간만 조절) |
| 02 2차 사고 방지 | Mercedes Car-to-X(고장·사고 차량), VW Local Hazard Warning, 카카오내비+도로공사 정지차량 안내(고속도로, 도로공사 확인 후 안내) | 에어백·비상등·정차 신호로 즉시 자동 판단, 300m 안 재경고. 도로공사 확인 단계 없이 차량 신호로 |
| 03 기상·노면 | Mercedes(ABS·ESP로 미끄러운 노면), Audi(군집 데이터로 결빙), 카카오내비 결빙 취약 구간(정적 자료) | 와이퍼·안개등·ABS·ESC를 2대 이상 합의로 실시간 확정. 국내 브랜드 차량 신호 기반 사례는 확인 못 함 |
| 04 정체·사고 구간 | 모든 내비의 실시간 교통(GPS 프로브), Waze 제보 | 내비를 대체하지 않는 보완재. 사고 확정/추정을 차량 신호로 구분 |
| 05 EV 충전 | 테슬라 도착 시점 혼잡 예측(자사 수퍼차저), E-pit 대기표(E-pit 충전소), EV Infra 실시간 상태·후기 | 공공 충전망 전체(모든 브랜드) + 실측 출력·충전 기록·별점을 합친 도착 순번·완료 시각 |
| 06 긴급차량 | HAAS Alert(긴급차량 송신기 → Stellantis 차량·Waze, 약 30초 전 경고), Waze 긴급차량 표시 | 긴급차량도 같은 앱 하나로, 차로까지 안내("같은 차로, 오른쪽으로 비켜 주세요"). 국내 상용 사례는 확인 못 함 |
| 07 차로 변경 의도 | 연구 단계(Honda 연구소 "Driver Messenger", V2X 의도 공유 논문) | 상용 사례 확인 못 함. 옆 차로 60m 안 접근 차에만 알리는 단순 규칙으로 지금 SDK에서 구현 |
| 07·08 감사 인사·이모트 | 애프터마켓 LED 표시기(Drivemocion, MotorMood 등: 뒷유리에 "Thanks" 표시) | 차량 기능으로 상용 사례 확인 못 함. 소리로 전하고, 진입 성공 시 자동으로 보냄 |
| 08 동의·철회 | Mercedes Car-to-X도 계정 동의 후 익명 전송 | 같은 원칙. 철회 시 서버 데이터 삭제까지 |

보편적인 모빌리티 경험으로 만든다". 테슬라·벤츠·폭스바겐 사례는 아이디어가 실현 가능하다는 근거로 쓴다.
