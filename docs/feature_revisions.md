# Tier 1 기능별 개선 기록

기능을 고칠 때마다 개선판 번호(rev)를 올렸다. 아래 표의 번호(01~13)는 시연 영상의 장면 번호이고, 기획서의 ①~⑧과는 이렇게 대응한다: 01 = ① 급제동, 02 = ② 2차 사고, 03 = ③ 기상, 06 = ④ 긴급차량, 07 = ⑤ 차로 변경, 08 = ⑥ 이모트, 05 = ⑦ EV 충전, 09·10 = ⑧ 기본 화면, 11 = 이모트 스토어.

## 기존 서비스와의 비교
결론: 개별 기능은 대부분 해외 프리미엄 브랜드·내비 앱에 이미 있다. 새로움은 "기능 하나"가 아니라 아래 조합에 있다.
1. **국내 점유율로 밀도 확보**: 차량 간 경고는 장착 차량이 많아야 효과가 난다(유럽 신차 안전 평가 Euro NCAP도 VW Car2X를 평가하며 같은 한계를 언급).
   현대차그룹은 국산 완성차 판매의 90% 이상이라, 자사 충전소·자사 망이 아니어도 기본 탑재 이후에는 공공 도로·공공 충전망을 덮을 수 있다.
2. **차량 신호 + 대상 선택**: 진행 방향과 도달 시간으로 곧 만날 뒤차에만 급제동을, 옆에서 다가오는 차에만 차로 변경 알림을 보내는 등 "누구에게 보낼지"를 고른다(차로 단위 선별은 Tier 2).
3. **사람 사이의 소통(소리 이모트·자동 감사 인사)**: 상용 차량 기능은 찾지 못함. 애프터마켓 뒷유리 LED 표시기만 있음.
4. **추가 설치 없이 소프트웨어로**: VW Car2X는 전용 통신 칩(802.11p), HAAS는 긴급차량 송신기가 필요. OverRoad는 기존 차량 신호 + 이동통신.

## 05 EV 충전 rev2 (2026-11-05)
문제: 충전소의 평균 충전 시간·충전 중 대수, 같은 충전소로 오는 차량의 위치·SoC, 타사 차량까지 반영해
내 도착 순번·대기 시간·충전 완료 시각을 구해야 한다. 내가 충전한 기록이 다른 사람에게 새 충전 정보이자 별점이 되어야 한다.

| 항목 | rev1 | rev2 |
|---|---|---|
| 충전 중 차량 | OverRoad 차량만 | + 타사 차량: 공공 충전기 상태(충전 시작 시각)로 남은 시간 어림 |
| 평균 충전 시간 | 없음 | 서울 공공 급속 실이용 47.2분으로 시작 → 실측 기록이 쌓이면 대체 |
| 충전 출력 | 100kW 고정 | 정격의 80%로 시작 → OverRoad 차량의 실측 출력 평균 |
| 오는 차량 | 목적지·ETA | + 도착 시 SoC 어림(남은 거리 소모), 타사 도착은 시간당 도착 수로 통계 어림 |
| 결과 | 앞 대수·대기 분 | 도착 시각 · 내 순번 · 대기 · 충전 시작 · **80% 완료 시각** · 충전 중 차(타사 포함) |
| 대안 충전소 | 대기가 5분 이상 짧으면 | **충전 완료 시각**이 5분 이상 빠르면 |
| 내 충전 기록 | 없음 | 충전이 끝나면 시간·실측 출력이 충전소 정보로 자동 반영, 기여 통계에 집계 |
| 별점 | 없음 | 충전 후 정차 중 ★1~5 → 충전소 별점, 다른 운전자 카드에 표시 |

데이터 출처와 한계
- 공공 충전기 상태: 한국환경공단 전기차 충전소 정보 API(충전기 상태, 충전 시작 일시 등). 시연에서는 `POST /public_status`로 대신 넣는다.
- 내비 SDK의 충전 정보는 충전 사업자 목록뿐이라 상태는 공공 데이터를 쓴다.
- 차종별 배터리 용량·충전 곡선은 반영하지 않음(77.4kWh·일정 출력 가정). 실차 연동은 Tier 2.
- 시연에서는 충전 시간을 60배 빠르게 흘린다(`POST /demo`).

## 2026-11-05 2차 개선 (화면과 판별 규칙 개선)

### 전체 화면 개편 (모든 기능 공통)
문제: 검정·회색 앱 창이 내비를 가린다.
- Pleos는 오른쪽 패널에 앱 하나만 보여 준다. 반투명 창으로 띄워도 아래 내비가 숨겨지고(에뮬레이터 확인), 다른 앱 위에 그리기는 signature 권한이라 불가.
- 해결: **주행 중에는 내비가 앞**. 출발(5km/h 초과)하면 앱이 스스로 내비를 앞으로 부르고, 경고는 플랫폼 **상단 알림(헤즈업)** + 음성으로 낸다.
- 정차 중 앱을 열면 새 화면: 상태 줄 · 둥근 알림 카드 · 본문(대기 안내 / 충전소 지도 / 이모트 카드) · 팩 색 이모트 버튼. 진단 신호 목록은 설정 안으로.

### 05 EV rev3 (화면)
문제: 로직은 좋다, 글이 많아 한눈에 안 들어온다 → 별점이 있는 별도 지도 화면.
- 카드 두 줄: "⚡ 판교역 충전소 ★4.0" / "20:10 도착 → 21:11 완료 · 21분 대기" (+ 더 빨리 끝나는 곳 한 줄)
- 정차 중 **충전소 지도**: 핀 색(초록 바로·노랑 ~15분·빨강 그 이상), ★별점(평가 수), 80% 완료 시각, 목적지 굵은 테두리. 서버 `GET /chargers?vehicle=`

### 06 긴급차량 rev2
문제: 경찰·소방·구급마다 디자인이 달라야 한다.

**시험으로 확인한 플랫폼 제약 (에뮬레이터, 2026-11-06):** 내비 위에 작은 창을 띄우는 방법은 쓸 수 없다. 작은 반투명 창, 실행 영역 지정, 옆 창 실행, 화면 속 화면(PiP) 모두 내비가 숨겨지거나 동작하지 않았고, 다른 앱 위에 그리기 권한은 허용 화면 자체가 없다. 그래서 작은 바는 Pleos 홈 위에 떠 있고, 주행 중에는 내비 + 상단 알림 + 음성으로 동작한다.
